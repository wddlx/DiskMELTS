# V2 observation workflows

These are the recommended package APIs for fitting observed spectra. The model
workflow uses the production checkpoints installed under `diskmelts/models/`.
The grid workflow is optional and requires a user-supplied grid directory.

## Model registry and fitting

`MODEL_SPECS` maps each molecule to its checkpoint, trained wavelength and
physical domain, PCA size, hidden-layer sizes, and `grid_sigma=0` for the
original checkpoints. `SIGMA2_MODEL_SPECS` records separate checkpoints for
all species with supplied sigma=2 grids, including C6H6 at 13–17 µm and
100–675 K, and OH at 15–26 µm.
The sigma=2 C2H2 bank has
6–9 and 11.5–17 µm tiles. `load_fitting_models` loads
only requested checkpoints and checks their settings. It reads no slab grids.
For array fits, select the bank with `load_fitting_models` and pass it to
`fit_stage`; its existing `sigma` fitting option remains the observed noise.

```{eval-rst}
.. autofunction:: diskmelts.v2_fitting.load_fitting_models

.. autofunction:: diskmelts.v2_fitting.fit_stage

.. autofunction:: diskmelts.v2_fitting.fit_observation
```

Use `fit_stage` for arrays already in memory. Use `fit_observation` for ordered
stages and saved CSV products. The `root` argument is an optional checkpoint
override; leave it unset for the bundled models. Both accept `distance_pc`,
which converts the model's 140 pc normalization into physical area at the
source distance.
In a joint model stage, `isotopologue_groups`, `Tshare`, and `Ashare` can tie
each rare isotopologue's temperature and area to its main species or require
the rare temperature to be lower. The {doc}`fitting quick start <../quickstart>`
follows the current `Example_Fitting` notebook configuration.
Both model and direct-grid stages can fit repeated molecules jointly when
`component_names` gives each copy a unique label. Bounds dictionaries can
then use those labels for separate T, logN, and log10(A) ranges.

## Saved results and plots

```{eval-rst}
.. autofunction:: diskmelts.v2_read_plot.read_stage_result

.. autofunction:: diskmelts.v2_read_plot.plot_saved_observation
```

These functions read fit CSVs, verify the sequential residuals, and plot the
observation and components. They do not load models or grids.

`plot_literature_comparisons` creates one four-parameter paper-versus-fit
figure per molecule from a comparison table with paper and fitted values and
uncertainties. It also writes mean and sample-standard-deviation statistics.

```{eval-rst}

```

## Optional direct-grid fitting

Pass `grid_root` explicitly (for example, `Model_grids/sigma0`). A missing root or molecule grid fails with a
clear error. Grid spectra must be complete across the requested T/logN domain.
The `sigma` argument of `fit_grid_stage` currently means observed flux noise;
it does not select the grid broadening. Choose the grid set through `grid_root`.
The direct-grid workflow does not implement isotope temperature or area
constraints. Passing `isotopologue_groups`, `Tshare`, `Ashare`, or
`shared_area_groups` in a grid stage raises an error. Remove those keys
explicitly when making an unconstrained grid comparison.

```{eval-rst}
.. autofunction:: diskmelts.v2_grid_fitting.load_grid_cube

.. autofunction:: diskmelts.v2_grid_fitting.fit_grid_stage

.. autofunction:: diskmelts.v2_grid_fitting.fit_observation_grids

.. autofunction:: diskmelts.v2_grid_fitting.combine_grid_uncertainty
```

The grid uncertainty is a local covariance estimate with the full local grid
step added in quadrature to T and logN. It is not a posterior credible interval.
