# V2 observation workflows

These are the recommended package APIs for fitting observed spectra. The model
workflow uses the production checkpoints installed under `diskmelts/models/`.
The grid workflow is optional and requires a user-supplied grid directory.

## Model registry and fitting

`MODEL_SPECS` maps each molecule to its checkpoint, trained wavelength and
physical domain, PCA size, hidden-layer sizes, and `grid_sigma=0` for the
original checkpoints. `SIGMA2_MODEL_SPECS` records separate checkpoints for
all 18 species, including C6H6 at 13–17 µm and 100–675 K, and OH at
15–26 µm. Both C2H2 banks have 6–9 and 11.5–17 µm tiles, and OH is
available at both sigmas (the sigma=0 OH and 6–9 µm C2H2 checkpoints were
added in 2.2.1). `load_fitting_models` loads
only requested checkpoints and checks their settings. It reads no slab grids.
`fit_stage` takes models loaded this way; `fit_observation` loads them
itself.
For a single synthetic molecule, `synthesize_spectrum` returns wavelength and
flux from `T`, `logN`, and `A` without local grids; see {doc}`../generate_spectra`.


## `fit_stage` or `fit_observation`?

Both fit the bundled models to a continuum-subtracted spectrum. `fit_stage`
is one fit; `fit_observation` is a whole multi-stage run built from
`fit_stage` calls.

| | `fit_stage` | `fit_observation` |
| --- | --- | --- |
| Spectrum input | `obs_wav`, `obs_flux` arrays (positional) | a CSV path **or** `obs_wav=`, `obs_flux=`, `obs_err=` arrays |
| Models | you load them with `load_fitting_models` | loaded for you (`sigma=0` or `2`) |
| Noise level | optional `sigma=` in Jy | estimated: median `obs_err`, else line-free scatter |
| Stages | one stage (one or several molecules) | ordered list; each fits the previous residual |
| Detection screening | no | optional per stage (`detect_peaks`) |
| Files written | none | per-stage CSVs and `Fitted_Parameters.csv` |
| Returns | one fit result | `fits` (one `fit_stage` result per stage), residual, noise, file paths |

What `fit_observation` does, step by step:

1. Reads the spectrum from `input_path` or takes the `obs_wav`/`obs_flux`
   arrays, and drops nonfinite pixels.
2. Loads the models for every molecule named in `stages`.
3. Estimates one noise value: the median of `obs_err`, or the scatter in
   `line_free_windows` when no errors are given.
4. For each stage, in order: screens for detections (if the stage has
   `detect_peaks` and `detection_screening=True`), calls `fit_stage` on the
   current residual, and subtracts the best-fit model.
5. Saves the stage CSVs and returns all results.

Give the spectrum as a file or as arrays, never both:

```python
from diskmelts import fit_observation, plot_saved_observation

stages = [{'name': 'hcn', 'mol': 'HCN',
           'wavelength_range': (11.5, 17.0), 'fit_ranges': (13.8, 14.2)}]

# 1. From a CSV (first two columns: wavelength in µm, flux in Jy).
result = fit_observation('my_spectrum.csv', stages, name='my_source',
                         output_dir='results/my_source', distance_pc=140.0)

# 2. From arrays you already have (FITS, consub.calculate, your own reader).
result = fit_observation(stages=stages, obs_wav=wave, obs_flux=flux,
                         obs_err=error,  # optional
                         name='my_source', output_dir='results/my_source',
                         distance_pc=140.0)

# Plot from the same input; arrays work here too.
plot_saved_observation(result_dir='results/my_source', stages=stages,
                       obs_wav=result['obs_wav'], obs_flux=result['obs_flux'],
                       name='my_source', show=True, savefig=False)
```

With arrays, pass `stages` (and everything after it) by keyword, because the
first positional argument is `input_path`. `obs_err` only sets the noise
level; it does not weight individual pixels in the fit.
`fit_observation_grids` and `plot_saved_observation` accept the same two
input forms.

```{eval-rst}
.. autofunction:: diskmelts.v2_fitting.fit_stage

.. autofunction:: diskmelts.v2_fitting.fit_observation
```

The `root` argument is an optional checkpoint override; leave it unset for
the bundled models. Both functions accept `distance_pc`, which converts the
model's 140 pc normalization into physical area at the source distance.
In a joint model stage, `isotopologue_groups`, `Tshare`, and `Ashare` can tie
each rare isotopologue's temperature and area to its main species or require
the rare temperature to be lower. The {doc}`fitting quick start <../quickstart>`
follows the current `Example_Fitting` notebook configuration.
Both model and direct-grid stages can fit repeated molecules jointly when
`component_names` gives each copy a unique label. Bounds dictionaries can
then use those labels for separate T, logN, and log10(A) ranges.

## Optional direct-grid fitting

Pass `grid_root` explicitly (for example, `Model_grids/sigma0`). A missing root or molecule grid fails with a
clear error. Grid spectra must be complete across the requested T/logN domain.
The `sigma` argument of `fit_grid_stage` currently means observed flux noise;
it does not select the grid broadening. Choose the grid set through `grid_root`.
Grid stages accept the same `isotopologue_groups`, `Tshare`, `Ashare`, and
`shared_area_groups` ties as model stages. Tied components share free fit
coordinates, so their posterior samples respect the ties.
Remove those keys explicitly when you want an unconstrained grid comparison.

```{eval-rst}
.. autofunction:: diskmelts.v2_grid_fitting.load_grid_cube

.. autofunction:: diskmelts.v2_grid_fitting.fit_grid_stage

.. autofunction:: diskmelts.v2_grid_fitting.fit_observation_grids

.. autofunction:: diskmelts.v2_grid_fitting.combine_grid_uncertainty
```

Grid error bars are the posterior 16–84% range sampled on the interpolated
grid (see {doc}`uncertainty`), with the full local grid step added in
quadrature to each side for T and logN. As for model fits, pass
`errorbars=False` to report best fits only.
